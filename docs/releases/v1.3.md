# AI Growth Notes v1.3.0 — AI Daily

AI関連の公式RSS/Atomを手動更新し、短い概要をSQLiteへ保存して毎日確認できます。取得元の一部が失敗しても残りを処理し、全Feedが失敗しても既存データは削除されません。

## データと重複排除

`ai_daily_items` は正規化URLとフォールバックハッシュに一意Indexを持ちます。更新時は記事情報だけを更新し、既読、お気に入り、保存済みNote IDを保持します。`ai_daily_editions` は日付単位のLearning/Practiceを保持します。既存`notes`のSchemaやデータは変更しません。

## セキュリティと制限

HTTP/HTTPS以外のURLを拒否し、追跡QueryとFragmentを除去します。XML応答サイズ、件数、Timeout、テキスト長を制限し、外部HTMLはテキスト化します。Frontendは記事データを`textContent`で描画します。外部記事全文は保存しません。

Geminiは任意です。新規記事のみ1回の更新で最大3件、タイトルと短い概要だけを利用します。Keyなし・不正JSON・Timeout・API失敗時はFeed概要とルールへフォールバックします。
