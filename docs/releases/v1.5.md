# v1.5.0 — Ask My Notes

保存したNotesとAI Dailyをもとに、質問、要約、振り返り、次の学習候補を提示するMVPです。

## 主な機能

- 認証必須の `/assistant`
- PostgreSQLによる関連記録検索
- 根拠不足時に学習履歴を捏造しない専用Prompt
- 回答で使用した記録のReferences
- Suggested Questionsとブラウザ内の最新20件履歴
- Gemini未設定・timeout・失敗時のretrieval-only fallback
- Responsive UI

Vector DB、pgvector、Web Search、Agent Loop、Tool Calling、Multi-user Memoryは含みません。
